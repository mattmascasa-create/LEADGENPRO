**New requirements added in this session:**
1.  **Admin/Employee Portals:** Create a strict role-based access system.
    -   **Admins (, ):** Can see a global dashboard with all employee performance, manage users (add/delete/modify), and distribute leads.
    -   **Employees:** Can only see their own daily goals, notes from admins, assigned leads, and personal progress. They cannot see other employees' data or admin-level information.

3.  **Mobile-Friendly UI:** The entire application needs to be responsive and easily usable on a mobile phone.
4.  **Disable Public Registration:** Prevent users from creating their own accounts. Specifically, new users should not be able to assign themselves the 'admin' role. All user creation must be done by an existing admin.
